Detailed Description

DVI output drawn one line at a time by your callback, with no frame buffer. For emulators and other code that generates each line itself.

Member Typedef Documentation

◆ ScanlineCallback

typedef pimoroni::DVHSTX::ScanlineCallback DVHSTXScanline::ScanlineCallback

Draws one output line into dst: width() RGB565 pixels, two per 32-bit word, low half first. Runs in the DMA interrupt for every active line (active_line from 0 to height()-1), so it must be fast and live in RAM (__not_in_flash_func). Same signature as Adafruit_DVI_Audio's callback.
